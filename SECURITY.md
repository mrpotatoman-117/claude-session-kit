# Security

This mod edits `~/.claude/settings.json` and a project's `.claude/settings.local.json`,
so a bug can change what a user's Claude Code loads. Please report one privately
rather than in a public issue, so a fix can ship before it is widely known.

Report it under the Security tab of this repository, "Report a vulnerability".
Include the steps to reproduce and which settings file was affected.

Only the latest release is supported. Everything else (bugs, ideas, questions) goes
in a normal issue.
